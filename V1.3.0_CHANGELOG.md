# Elements Baseball v1.3.0

## Cloudflare R2 — 2025 image delivery

- Routes existing public Supabase Storage URLs for `card-images/2025/*` to the matching Cloudflare R2 object path.
- Keeps the Supabase `card_images` table as the source of card-to-image relationships.
- Preserves filenames and card keys; no database migration is required for this release.
- Leaves non-2025 URLs and Google Drive URL normalization unchanged.
- Applies everywhere the shared card image normalization is used, including Cards, Card Profile, and Team Builder.

## Safety

- Supabase image objects are not deleted by this update.
- The existing Supabase URLs remain available as a rollback source until the published R2 build is verified.
