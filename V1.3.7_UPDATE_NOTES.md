# v1.3.7 Update Notes

## Cards
- Attribute Filters are arranged as one compact desktop row: label, attribute, operator, value, Fielding Position, DEF, Add Filter.
- Responsive layouts still stack safely at smaller widths.

## Player Profile
- Significantly reduced Player Profile header height.
- Desktop profile is constrained to the available viewport.
- Tab/content panel scrolls internally when its content exceeds the available height.

## Season Eligibility
- Centralized eligibility in `isSeasonEligibleCard` in `src/utils/cardHelpers.ts`.
- Current Elements season year is 1925.
- All 1925 cards are Season Eligible.
- Cards from other years are Season Eligible only when `source_yes_field` is `yes` or a recognized current manager name.
- Cards and Team Builder now use the same helper.
- Removed the stale 2025 current-season constant by mapping `ACTIVE_SEASON` to the shared 1925 season year.
